# KEKE POCKET

ぬいぐるみのケケを動かして、ぷにっと遊んで、いつもの景色と写真に残すPWA。

**アプリを開く: https://pishiko.github.io/lowpoly-keke-ar-demo/**

## 機能

- 297三角形・512pxのローポリモデル
- スティック／WASD／矢印キー／標準ゲームパッドで移動。画面外にも移動でき、「呼び戻す」で復帰
- 効果音付きの歩行・ぷにぷに・ジャンプ・転倒／起き上がり・回転
- 前後カメラ切替、カメラ映像と3Dの合成写真をPNG保存・共有
- 対応端末ではWebXRで床を検出して配置
- ホーム画面へのインストール、初回キャッシュ後のオフライン起動

## インストール

- Android：アプリ右上の「＋」またはブラウザメニューの「アプリをインストール」
- iPhone：Safariの共有メニュー →「ホーム画面に追加」

カメラモードは映像への合成で、床の位置は追跡しません。「床に置く AR」には `immersive-ar`、`hit-test`、`dom-overlay` 対応端末が必要です。このモードでは端末のスクリーンショットで撮影します。実機でのAR追跡は未検証です。

写真は端末内で合成し、最後の1枚を端末内に保存します。カメラ映像や写真をサーバーに送信せず、マイク権限も要求しません。

## 開発・公開

ビルド済みの静的アプリです。`main` ブランチのルートからGitHub Pagesで公開します。`.nojekyll` により、同梱したThree.jsランタイムもそのまま配信します。

```sh
python3 -m http.server 4173
```

PCで http://localhost:4173 を開くと確認できます。スマホからのカメラ利用にはHTTPSが必要です。

`main.js` と `app/` がアプリのコード、`dist/keke-lowpoly-300-tex512.glb` が採用モデルです。`node_modules/three/` には動作に必要なファイルとThree.jsのライセンスを同梱しています。外部CDNへの依存はありません。

モデル読み込み、全アクション、画面外移動・呼び戻し、疑似カメラでの写真合成・切替・停止、権限拒否、スマホ幅のスティック、オフライン再起動・写真履歴をChromeで自動検証済みです。
